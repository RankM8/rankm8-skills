# Glossar (einfach erklärt)

| Begriff | Erklärung |
|---|---|
| Alt-Text | Kurze Beschreibung eines Bildes im Code. Hilft der Bildersuche und Menschen mit Screenreader. |
| Backlink | Ein Link von einer anderen Website auf deine. Wie eine Empfehlung. |
| Canonical | Hinweis an Google, welche Adresse die „richtige“ ist, wenn es dieselbe Seite mehrfach gibt. |
| Core Web Vitals | Drei Messwerte von Google für Ladezeit (LCP), Reaktionszeit (INP) und Ruhe beim Laden (CLS). |
| Crawlen | Google (oder ein KI-Bot) ruft deine Seiten ab und liest sie. |
| CTR (Klickrate) | Wie viele von denen, die dein Ergebnis sehen, auch klicken. |
| GEO | Generative Engine Optimization: in Antworten von ChatGPT, Perplexity und Co. als Quelle auftauchen. |
| Google-Unternehmensprofil | Der Eintrag deiner Firma in Google Maps und rechts in der Suche (früher „Google My Business“). |
| H1 | Die Hauptüberschrift einer Seite. Eine pro Seite. |
| Impressionen | Wie oft dein Ergebnis in Google angezeigt wurde. |
| Index | Das Verzeichnis aller Seiten, die Google kennt. Nur was im Index ist, kann gefunden werden. |
| Keyword (Suchbegriff) | Das, was Menschen bei Google eintippen. |
| Keyword-Fit | Wie gut ein Suchbegriff zu deinem Angebot passt (Bewertung in RankM8). |
| llms.txt | Eine Textdatei, die KI-Systemen deine Website kurz zusammenfasst. Junger Standard, kein belegter Ranking-Faktor. |
| Local Pack | Der Kartenbereich mit drei Firmen bei Suchen wie „Friseur Köln“. |
| Meta-Beschreibung | Der Text unter dem Titel in den Google-Ergebnissen. |
| noindex | Anweisung an Google, eine Seite nicht aufzunehmen. Auf wichtigen Seiten ein schwerer Fehler. |
| robots.txt | Datei, die Bots sagt, welche Bereiche sie lesen dürfen. Regelt auch KI-Bots. |
| SERP | Die Ergebnisseite von Google zu einer Suche. |
| Search Console | Kostenloses Google-Werkzeug: zeigt, bei welchen Suchen deine Website erscheint und geklickt wird. |
| Seitentitel (Title) | Die blaue Überschrift in den Google-Ergebnissen. Ideal 50 bis 60 Zeichen. |
| Sitemap | Liste aller Seiten deiner Website für Suchmaschinen. |
| Strukturierte Daten (Schema.org) | Maschinenlesbare Angaben im Code, z. B. Firmenname, Adresse, Öffnungszeiten. |
| Suchintention | Was der Suchende eigentlich will: informieren, vergleichen oder kaufen/buchen. |
| Suchvolumen | Wie oft ein Begriff pro Monat gesucht wird (Durchschnitt). |
