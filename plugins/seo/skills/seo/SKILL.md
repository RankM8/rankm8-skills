# SEO mit RankM8: Einstieg

Der Nutzer ist oft Einsteiger: Gründer, Agentur, Coach, Berater oder Webdesigner. Sprich einfach,
erkläre Fachwörter beim ersten Vorkommen in Klammern und stelle höchstens eine Frage auf einmal.

## 1. Verbindung prüfen

RankM8-Tools vorhanden (z. B. `list_projects`)? Wenn nicht: `seo-setup` ausführen. Ohne Verbindung
gehen nur `seo-grundlagen`, `seo-geo` (ohne Messwerte), `seo-umsetzen` und `seo-verkaufen`.

## 2. Ziel klären

Frage: „Worum geht es dir gerade?“ und biete diese Antworten an:

| Ziel des Nutzers | Skill |
|---|---|
| „Ich will erst verstehen, wie SEO funktioniert“ | `seo-grundlagen` |
| „Schau dir mal schnell diese Website an“ (eigene, Kunde, Lead) | `seo-schnellcheck` |
| „Ich will meine Website (oder die eines Kunden) dauerhaft betreuen“ | `rankm8-project-setup`, danach `rankm8-site-audit` |
| „Für welche Suchbegriffe soll ich gefunden werden?“ | `rankm8-keyword-research` |
| „Schreib mir einen Text oder Blogartikel, der bei Google rankt“ | `rankm8-content-pipeline` |
| „Ich will in meiner Stadt gefunden werden“ (Google Maps, Bewertungen) | `seo-lokal` |
| „Ich will in ChatGPT, Perplexity oder Google-KI-Antworten auftauchen“ | `seo-geo` |
| „Bau die Verbesserungen auf meiner Website ein“ | `seo-umsetzen` |
| „Monatsbericht für mich oder meinen Kunden“ | `rankm8-reporting` |
| „Ich will SEO als Dienstleistung anbieten“ | `seo-verkaufen` |

Unklar? Dann mit `seo-schnellcheck` für die eigene Website beginnen: Das liefert in wenigen Minuten
ein Bild, auf dem alles Weitere aufbaut.

## 3. Typische Wege

- **Eigene Website, neu dabei:** `seo-schnellcheck` → `rankm8-project-setup` → `rankm8-site-audit` →
  `seo-umsetzen` → `rankm8-keyword-research` → `rankm8-content-pipeline` → monatlich `rankm8-reporting`.
- **Lokaler Betrieb:** zusätzlich `seo-lokal` direkt nach dem Projekt-Setup.
- **Agentur mit Kunden:** pro Kunde ein Projekt; neue Kunden gewinnen mit `seo-schnellcheck` und
  `seo-verkaufen`.

## Leitplanken

- Vor jedem Schritt, der Credits kostet, die Kosten nennen und auf ein Ja warten.
- Keine Ranking-Garantien, keine Zeitversprechen unter drei Monaten: SEO wirkt mit Verzögerung.
- Nur mit echten Daten aus RankM8 argumentieren; Schätzungen als Schätzung kennzeichnen.
